Apport 1 — Installer Node.js (10 min)

  • Pourquoi : lancer vos programmes JavaScript sur votre ordinateur.
  • Node.js exécute du JavaScript en dehors du navigateur.

Pourquoi. Cette semaine, vous écrivez des programmes et vous les faites vérifier par des tests, sur votre ordinateur. Le navigateur lit le JavaScript d’une page web, mais il ne lance pas un programme seul dans un terminal.

Définition. Node.js est un programme qui exécute du JavaScript en dehors du navigateur, dans un terminal.

On installe la version LTS (Long Term Support) : elle est maintenue longtemps, et c’est celle que Node.js recommande pour un usage sérieux (OpenJS Foundation, s. d.-b). La page de téléchargement officielle indique laquelle est active, et propose l’installeur qui correspond à votre système (OpenJS Foundation, s. d.-a).

Exemple. Une fois Node.js installé, ces deux commandes affichent chacune un numéro de version (pour Node, la lettre v suivie de chiffres).

Les blocs à fond sombre reproduisent l’écran du terminal de Windows (PowerShell). La ligne qui commence par PS C:\Users\stagiaire> est l’invite : le dossier où le terminal travaille, suivi de la commande tapée. Ne tapez que ce qui suit >. Les lignes suivantes sont la réponse du terminal. Sous macOS et Linux, l’invite est différente, la réponse est la même.

PS C:\Users\stagiaire> node -v
v24.21.0
PS C:\Users\stagiaire> npm -v
11.19.0

Vos numéros peuvent être un peu différents : l’installation est réussie si chaque commande affiche un numéro, et si celui de Node commence par v24 ou plus.

Apport 2 — Un éditeur de code : VS Code (10 min)

  • Pourquoi : écrire vos fichiers .js et les retrouver.
  • VS Code : l’éditeur de code de la formation, gratuit.

Pourquoi. Cet après-midi, vous modifiez des fichiers .js. Un traitement de texte ajoute une mise en forme que Node ne sait pas lire, et le Bloc-notes peut enregistrer hello.js sous le nom hello.js.txt. Un éditeur de code enregistre du texte brut, colore le code et numérote les lignes.

Définition. VS Code (Visual Studio Code, de Microsoft) est un éditeur de code : un logiciel gratuit pour écrire et enregistrer des fichiers de programmation. C’est l’éditeur de toute la formation.

Exemple. Un fichier essai.js, créé dans VS Code et enregistré dans dwwm/semaine-02, qui contient une ligne :

console.log('Bonjour depuis VS Code');

Apport 3 — const et let (8 min)

  • Pourquoi : garder une valeur pour la réutiliser plus loin.
  • Variable : un nom qui désigne une valeur ; const par défaut.

Pourquoi. Un programme calcule une valeur, puis s’en sert plus loin : un prénom, un âge, un score. Pour la retrouver, on lui donne un nom.

Définition. Une variable est un nom qui désigne une valeur. On la déclare avec const (le nom désigne toujours la même valeur) ou avec let (le nom peut ensuite désigner une autre valeur) (MDN Web Docs, s. d.-e). Règle du cours : const par défaut, let seulement si la valeur doit changer.

Une image, avec sa limite. Pour s’en souvenir, on peut imaginer une étiquette portant le nom, collée sur une valeur : const colle l’étiquette pour de bon, let permet de la décoller et de la recoller ailleurs. Limite de l’image : en semaine 6, deux étiquettes pourront désigner le même objet, et modifier l’objet par l’une se verra par l’autre ; l’image sera alors complétée.

Exemple.

const city = 'Brest';
let score = 12;
score = 15;
console.log(city, score); // Brest 15

Pas à pas. Le formateur tape chaque ligne au vidéoprojecteur ; vous la retapez aussitôt dans votre terminal.

  1. Tapez node, puis Entrée. L’invite > apparaît : vous êtes dans le REPL, la console interactive de Node.
  2. Tapez const city = 'Brest', puis Entrée. Le REPL affiche undefined : c’est normal, une déclaration ne renvoie aucune valeur.
  3. Tapez city, puis Entrée. Le REPL affiche 'Brest'.
  4. Tapez let score = 12, puis Entrée ; puis score = 15, puis Entrée. Le REPL affiche 15.
  5. Tapez console.log(city, score), puis Entrée. Le REPL affiche Brest 15, puis undefined (la valeur renvoyée par console.log, à ignorer) (MDN Web Docs, s. d.-a).
  6. Tapez .exit, puis Entrée, pour quitter le REPL.

Variables — attention et vérification

AvertissementAttention

TypeError: Assignment to constant variable. : vous avez donné une nouvelle valeur à une const. Déclarez-la avec let, seulement si sa valeur doit changer.

  • Vérifiez : let n = 10; n = n + 5; : que vaut n ?
  • Prédisez, puis tapez la ligne dans le REPL.

Apport 4 — Les types et typeof (7 min)

  • Pourquoi : '4' + 2 ne donne pas 6.
  • Type : la sorte d’une valeur ; typeof la donne.

Pourquoi. Le même signe ne fait pas la même chose selon les valeurs : 4 + 2 donne 6, mais '4' + 2 donne '42'. Pour comprendre un résultat, il faut connaître le type de chaque valeur.

Définition. Le type d’une valeur dit de quelle sorte elle est : un nombre (number), un texte (string), vrai ou faux (boolean)… L’opérateur typeof renvoie ce type, sous forme de texte (MDN Web Docs, s. d.-c). Un texte s’écrit entre guillemets : '42' est un texte, 42 est un nombre.

Exemple.

typeof 42     // 'number'
typeof '42'   // 'string'
typeof true   // 'boolean'
'4' + 2       // '42' : + colle deux textes
'4' * 2       // 8 : * convertit le texte en nombre

Pas à pas. Le formateur tape chaque ligne au vidéoprojecteur ; vous la retapez aussitôt.

  1. Ouvrez le REPL : node, puis Entrée.
  2. Tapez typeof 42, puis Entrée. Le REPL affiche 'number'.
  3. Tapez typeof '42', puis Entrée. Le REPL affiche 'string' : les guillemets font un texte.
  4. Tapez '4' + 2, puis Entrée. Le REPL affiche '42', entre guillemets : c’est un texte.
  5. Tapez '4' * 2, puis Entrée. Le REPL affiche 8, sans guillemets : c’est un nombre.
  6. Tapez .exit, puis Entrée.

Le texte placé après // est un commentaire : Node l’ignore. JavaScript accepte les guillemets simples ('…') et doubles ("…") ; le cours utilise les simples dans le code.

Types — attention et vérification

AvertissementAttention

+ avec un texte colle au lieu d’additionner : '4' + 2 donne '42'. Vous le voyez aux guillemets du résultat. Convertissez d’abord : Number('4') + 2 donne 6.

  • Vérifiez : que donne typeof 'true' ?
  • Prédisez, puis tapez-le dans le REPL.

Exercice — Prédire, puis vérifier (30 min)

  1. Ensemble (5 min) : prédisez à voix haute les lignes 1 et 7.
  2. Seuls, sur papier (10 min) : prédisez les lignes 2 à 9.
  3. Dans le REPL (10 min) : tapez chaque ligne, comparez.
  4. Lignes 7 à 9 en étiquettes, sur papier (5 min).
  5. Réussi si : chaque erreur de prédiction a sa raison écrite.
  1. typeof 42
  2. typeof '42'
  3. typeof true
  4. typeof undefined
  5. '4' + 2
  6. '4' * 2
  7. let x = 5; x = x + 1; x
  8. const y = 3; y = 4
  9. let a = 5; let b = a; a = 7; b

Les étiquettes sur papier : dessinez la mémoire pendant que le programme avance, comme le schéma de l’apport sur les variables.

  1. Recopiez la ligne 7 en mettant une instruction par ligne.
  2. Sous chaque instruction, dessinez les étiquettes : un nom, une flèche, une valeur.
  3. Quand une étiquette est recollée, barrez l’ancienne flèche et tracez la nouvelle.
  4. Recommencez avec les lignes 8, puis 9. À la ligne 9, écrivez la valeur de b après a = 7.
  5. Vérifiez la valeur finale de chaque ligne dans le REPL.

Réussi si : la valeur entourée sur votre dessin est celle qu’affiche le REPL.

Apport 5 — Comparer avec === (10 min)

  • Pourquoi : un programme doit savoir si deux valeurs sont égales.
  • === : même type et même valeur ; jamais ==.

Pourquoi. Un programme compare sans cesse : la réponse est-elle la bonne ? L’âge vaut-il 18 ? Un test vérifie que le résultat obtenu est égal au résultat attendu.

Définition. === (égalité stricte) renvoie true si les deux valeurs ont le même type et la même valeur, sinon false. == tente d’abord une conversion vers un type commun avant de comparer (MDN Web Docs, s. d.-b) : c’est la source des surprises. Règle du cours : toujours ===, et !== pour « différent ».

Exemple.

3 === 3     // true
'3' === 3   // false : un texte, un nombre
'3' == 3    // true : == a converti le texte
3 !== 4     // true : 3 est différent de 4

Pas à pas. Le formateur tape chaque ligne ; vous la retapez aussitôt.

  1. Ouvrez le REPL : node, puis Entrée.
  2. Tapez 3 === 3, puis Entrée : true.
  3. Tapez '3' === 3, puis Entrée : false, car un texte n’est jamais strictement égal à un nombre.
  4. Tapez '3' == 3, puis Entrée : true, car == a converti le texte en nombre avant de comparer.
  5. Tapez 3 !== 4, puis Entrée : true.
  6. Tapez .exit, puis Entrée.

=== — attention et vérification

AvertissementAttention

Un seul = ne compare pas : il donne une valeur. score = 3 change score ; score === 3 pose la question. Une variable qui change sans raison : cherchez un = seul.

  • Vérifiez : que donne '5' === 5 ?
  • Prédisez, puis tapez-le dans le REPL.

  2. Seuls (5 min) : écrivez true ou false pour 2 à 4.
  3. Dans le REPL (3 min) : vérifiez chaque comparaison.
  4. Réussi si : chaque surprise est entourée et expliquée.
  1. 3 === 3
  2. '3' === 3

Apport 6 — Lancer un programme et ses tests (15 min)

  • Pourquoi : vérifier un programme sans tout relire à la main.
  • Test : il lance votre programme et compare au résultat attendu.

Pourquoi. Relire un programme ne suffit pas à savoir s’il fait ce qui est demandé. Un test le vérifie pour vous, de la même façon à chaque fois, en une commande.

Définition. Un test est un petit programme qui lance le vôtre et compare ce qu’il affiche (le résultat obtenu) avec ce qu’il devrait afficher (le résultat attendu). Chaque exercice a son fichier de tests, qui finit par .test.js (OpenJS Foundation, s. d.-d). node 01-hello.js lance un programme ; node --test 01-hello.test.js lance ses tests.

Exemple. Un test rouge, au départ de l’exercice 01 : + actual est ce que votre programme affiche, - expected ce qu’il devrait afficher.   2. Tapez node --test 01-hello.test.js, puis Entrée. Une croix rouge ✖ apparaît : le test échoue. C’est normal au départ.
  3. Cherchez les lignes qui commencent par + et par -. + : ce que votre programme affiche ('À faire'). - : ce qu’il devrait afficher ('Hello, world!').
  4. Dans VS Code, ouvrez 01-hello.js. Lisez l’énoncé, en commentaire en haut du fichier.
  5. Remplacez 'À faire' par 'Hello, world!'. Enregistrez avec .
  6. Relancez node --test 01-hello.test.js. Une coche verte ✔ apparaît : le test passe.

Vous devez voir : une coche ✔ devant le nom du test, et ℹ fail 0.

node --test sans nom de fichier lance tous les tests du dossier, y compris ceux des exercices de vendredi : beaucoup de croix rouges, c’est normal. Pour un seul exercice, donnez le nom de son fichier de tests.

Les lignes fournies : process.argv. node 02-presentation.js Ada 36 lance le programme avec deux mots en plus. process.argv contient les arguments de la ligne de commande : le chemin de Node, celui du fichier, puis ce que vous tapez ensuite (OpenJS Foundation, s. d.-c). Ici, process.argv[2] vaut 'Ada' et process.argv[3] vaut '36' : ce sont des textes, que Number(…) convertit. Ces lignes sont fournies en haut des exercices : ne les modifiez pas. Vous écrirez vos propres fonctions la semaine prochaine.

Apport 7 — Une valeur dans un texte (5 min)

  • Pourquoi : afficher une phrase qui contient une valeur.
  • Littéral de gabarit : un texte entre accents graves ; ${…} insère.

Pourquoi. L’exercice 02 doit afficher une phrase qui contient un prénom et un âge. Coller des morceaux avec + est long et source d’erreurs.

Définition. Un littéral de gabarit est un texte écrit entre accents graves (`), dans lequel ${…} insère la valeur d’une variable ou d’un calcul (MDN Web Docs, s. d.-d).

Exemple.

const firstName = 'Ada';
console.log(`Bonjour ${firstName} !`); // Bonjour Ada !

Pas à pas. Le formateur tape chaque ligne dans le REPL ; vous la retapez aussitôt.

  1. Ouvrez le REPL : node, puis Entrée.
  2. Tapez const firstName = 'Ada', puis Entrée.
  3. Tapez console.log(`Bonjour ${firstName} !`), puis Entrée. Le REPL affiche Bonjour Ada !.
  4. Tapez console.log(`L'an prochain : ${36 + 1} ans`), puis Entrée. Le REPL affiche L'an prochain : 37 ans : on peut aussi calculer dans ${…}.
  5. Tapez .exit, puis Entrée.

L’accent grave s’obtient sous Windows (clavier AZERTY) avec , puis la touche Espace ; sous macOS, avec la touche située à gauche de Entrée (clavier AZERTY).

Littéral de gabarit — attention et vérification

AvertissementAttention

Avec des guillemets '…', ${firstName} s’affiche tel quel. Seuls les accents graves `…` remplacent ${…} par la valeur.

  • Vérifiez : que donne `${2 + 3} ans` ?
  • Prédisez, puis tapez-le dans le REPL.
