Semaine 9 — Fiche de révision

Formateur

Kevin Bardoux

Une page pour réviser la semaine. Lisez-la une fois, puis cachez-la et redites chaque point avec vos mots. Le détail de chaque notion est dans la page de la demi-journée.

La faille XSS (lundi matin, reportée du vendredi 27/11)

  • Les trois points à retenir sont dans la fiche de révision de la semaine 8.
  • Pour s’en souvenir : toute donnée extérieure s’affiche avec textContent, jamais avec innerHTML.

setTimeout et l’ordre d’exécution (lundi après-midi)

  • setTimeout(fonction, délai) : la fonction s’exécutera plus tard ; le délai est en millisecondes.
  • Le code n’attend pas : les lignes écrites après setTimeout s’exécutent avant sa fonction.
  • On donne la fonction sans parenthèses : setTimeout(show, 2000), pas show().

Les promesses (mardi matin)

  • Une promesse : une valeur qui arrive plus tard ; en attente, puis tenue.
  • then(fonction) : la fonction reçoit la valeur, à son arrivée.
  • Une chaîne : chaque then reçoit ce que le précédent a renvoyé.

async / await (mardi après-midi)

  • await attend une promesse et donne sa valeur : const museum = await loadMuseum(id);.
  • async devant function : obligatoire pour écrire await ; la fonction renvoie une promesse.
  • await met la fonction en pause, pas la page.

Une carte qui réagit (mercredi)

  • :hover : l’élément survolé par la souris ; :focus-visible : l’élément atteint au clavier.
  • transition s’écrit sur l’élément, pas sur :hover : le changement se fait en douceur, dans les deux sens.
  • object-fit: cover remplit le cadre sans déformer l’image ; overflow: hidden coupe ce qui dépasse.

Gérer les erreurs (jeudi matin)

  • throw new Error('message') : la fonction s’arrête et lève une erreur.
  • try { … } catch (error) { … } : la fin du try est sautée, catch affiche error.message.
  • Avec await, une promesse rompue lève une erreur : le même catch l’attrape.

fetch et response.ok (jeudi après-midi)

  • await fetch(adresse) envoie une requête et donne la réponse du serveur.
  • response.ok se vérifie avant de lire : un 404 ne lève pas d’erreur tout seul.
  • await response.json() transforme la réponse en objets JavaScript.
  • Projet, US-4 : le message de chargement s’écrit avant le await.

JSON et localStorage (vendredi matin)

  • localStorage ne garde que du texte : setItem, getItem, removeItem.
  • JSON.stringify pour enregistrer un tableau ou un objet ; JSON.parse pour le relire.
  • Rien d’enregistré : getItem renvoie null ; traitez ce cas d’abord.
