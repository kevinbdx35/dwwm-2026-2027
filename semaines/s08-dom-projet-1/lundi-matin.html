Objectifs

  • Expliquer ce qu’est le DOM : la page vue par JavaScript, comme un arbre d’éléments.
  • Trouver un élément avec querySelector, puis changer son texte avec textContent.
  • Créer un élément avec createElement, puis l’ajouter à la page avec append.

Comment se passe la matinée. Une seule notion : le DOM, pour lire et modifier la page. Jusqu’ici, votre JavaScript tournait dans le terminal, avec Node ; cette semaine, il tourne dans la page, dans le navigateur. D’abord une démonstration lente, puis nous codons ensemble, une étape à la fois, puis vos exercices, en trois paliers.

Les exercices de la semaine. Comme en semaine 7, trois paliers : le palier 1 est le minimum, guidé ; le palier 2 est recommandé, semi-guidé ; le palier 3 est autonome. Ce matin, les exercices se vérifient dans le navigateur : la page doit afficher ce qui est demandé, sans erreur dans la console. Cet après-midi aussi ; demain matin, les tests reviennent.

Le DOM (15 min)

  • Pourquoi : afficher des données dans la page.
  • DOM : la page vue par JavaScript, un arbre d’éléments.
  • Trouver, changer : querySelector, textContent.
  • Créer, ajouter : createElement, append.

Pourquoi. Jusqu’ici, le texte de vos pages était écrit à la main dans le HTML. Pour afficher 34 musées à partir d’un fichier de données, ou, cet après-midi, réagir à un clic, JavaScript doit lire et modifier la page.

Définition. Le DOM (Document Object Model) représente la page sous forme d’un arbre d’objets que JavaScript peut lire et modifier (MDN Web Docs, s. d.-f). document.querySelector(sélecteur) renvoie le premier élément qui correspond à un sélecteur CSS, ou null (MDN Web Docs, s. d.-b) ; textContent lit ou remplace le texte d’un élément (MDN Web Docs, s. d.-e) ; document.createElement('li') crée un élément, qui n’est pas encore dans la page (MDN Web Docs, s. d.-a) ; append l’ajoute à la fin d’un autre élément (MDN Web Docs, s. d.-c).

Le DOM, en image

Le texte du schéma : le document contient body, qui contient un titre h1#titre, un paragraphe p#ville et une liste ul#domaines. querySelector('#titre') trouve le titre ; textContent change son texte. createElement('li') crée un nouvel élément, et append l’ajoute dans la liste. Le même arbre est visible dans les outils du navigateur (F12), onglet Éléments.

Le DOM, l’exemple minimal

Le premier programme de la notion, annoté :

semaine-08/exemple/app.js
1const title = document.querySelector('#titre');
2title.textContent = 'musée de Dinan';

3const item = document.createElement('li');
4item.textContent = 'Histoire';
5document.querySelector('#domaines').append(item);
1
querySelector reçoit un sélecteur CSS, comme en semaine 5 : #titre désigne l’élément d’id="titre". La variable title désigne cet élément.
2
textContent remplace le texte de l’élément : la page change aussitôt.
3
createElement crée un élément li. Il n’est pas encore dans la page : il n’existe que dans la variable item.
4
On lui donne son texte, toujours avec textContent.
5
append l’ajoute à la fin de la liste #domaines : maintenant, il apparaît.

Le DOM — attention et vérification

AvertissementAttention

TypeError: Cannot set properties of null (setting 'textContent') : querySelector n’a rien trouvé, il a renvoyé null. Un # oublié, une faute dans le nom ? Comparez le sélecteur avec l’id dans l’onglet Éléments (fiche « Lire un message d’erreur »).

  • Vérifiez : quel sélecteur pour <p id="resume"> ?
  • Un li créé, sans append : est-il dans la page ?

Pas à pas ensemble — La fiche d’un musée (40 min)

  • Le formateur code, vous tapez en même temps, une étape à la fois.
  • Vous tapez aussi les commentaires : // en JavaScript.
  • Dossier : pas-a-pas-dom, fichiers index.html et app.js.
  • Perdu ? Dossier rattrapage/dom/, une étape à la fois.

Pas à pas. Dans VS Code, ouvrez pas-a-pas-dom/index.html : un titre, un paragraphe et une liste vide, chacun avec un id. Ouvrez aussi pas-a-pas-dom/app.js : il contient déjà les données d’un musée de Concarneau, tirées de la base Muséofile (Ministère de la Culture, s. d.). La page charge app.js par la ligne <script src="app.js"></script>, placée à la fin du body : quand le script s’exécute, les éléments existent déjà.

Les commentaires. Dans chaque pas à pas, vous tapez le code et ses commentaires : ils disent ce que fait la ligne et le nom de la notion. En JavaScript, un commentaire commence par // ; en HTML, il s’écrit <!-- … -->. Il est sur sa propre ligne, juste au-dessus de la ligne qu’il explique. Le navigateur les ignore : ils servent à vous relire.

Avant de commencer. Ouvrez pas-a-pas-dom/index.html avec Live Preview, puis Ouvrir dans le navigateur ; F12, onglet Console. Vous devez voir : la page « Titre à remplacer », et, dans la console, l’objet du musée, sans erreur en rouge. Chaque étape ajoute ses lignes à la fin d’app.js ; enregistrez, puis rechargez la page du navigateur.

Étape 1 — Trouver un élément. À la fin d’app.js, cherchez le titre avec querySelector, puis affichez-le dans la console.

Avant d’exécuter : que va afficher la console, le texte du titre ou l’élément entier ?

semaine-08/pas-a-pas-dom/app.js
// querySelector : trouve l'élément d'id titre
const title = document.querySelector('#titre');
// Affiche l'élément trouvé dans la console
console.log(title);

Enregistrez, puis rechargez la page du navigateur.

Vous devez voir, dans la console : <h1 id="titre">Titre à remplacer</h1>. Survolez-le : le titre s’éclaire dans la page.

Perdu ? Copiez rattrapage/dom/etape-1/app.js à la place de votre app.js, puis repartez avec le groupe.

Étape 2 — Changer le texte. Remplacez le texte du titre et celui du paragraphe de la ville.

Avant d’exécuter : le h1 du fichier index.html va-t-il changer ?

semaine-08/pas-a-pas-dom/app.js
// textContent : remplace le texte du titre
title.textContent = museum.name;
// Même chose pour le paragraphe de la ville
document.querySelector('#ville').textContent = museum.city;

Enregistrez, puis rechargez.

Vous devez voir : le titre « musée de la pêche » et la ville « Concarneau ». Le fichier index.html, lui, n’a pas changé : JavaScript modifie la page affichée, pas le fichier.

Perdu ? Copiez rattrapage/dom/etape-2/app.js à la place de votre app.js.

Étape 3 — Créer un élément. Créez un paragraphe, donnez-lui un texte, puis ajoutez-le à la fin de main.

Avant d’exécuter : sans la dernière ligne, le paragraphe serait-il visible ?

semaine-08/pas-a-pas-dom/app.js
// createElement : crée un paragraphe, pas encore affiché
const note = document.createElement('p');
// Son texte
note.textContent = 'Un musée de France, en Bretagne.';
// append : l'ajoute à la fin de <main>
document.querySelector('main').append(note);

Enregistrez, puis rechargez.

Vous devez voir : sous la liste vide, la phrase « Un musée de France, en Bretagne. ». Dans l’onglet Éléments, le nouveau <p> est à la fin de <main>.

Perdu ? Copiez rattrapage/dom/etape-3/app.js à la place de votre app.js.

Étape 4 — Une liste à partir d’un tableau. Pour chaque domaine du musée, créez un <li> et ajoutez-le à la liste.

Avant d’exécuter : combien de <li> vont apparaître ?

semaine-08/pas-a-pas-dom/app.js
// La liste des domaines, vide pour l'instant
const list = document.querySelector('#domaines');
// for...of : une fois pour chaque domaine
for (const domain of museum.domains) {
  // Un nouveau <li> pour ce domaine
  const item = document.createElement('li');
  // Son texte : le nom du domaine
  item.textContent = domain;
  // append : l'ajoute à la fin de la liste
  list.append(item);
}

Enregistrez, puis rechargez.

Vous devez voir : sous « Domaines », trois lignes : Ethnologie, Histoire, Sciences de la nature.

Perdu ? Copiez rattrapage/dom/etape-4/app.js à la place de votre app.js.

Étape 5 — Masquer un élément. Masquez le paragraphe créé à l’étape 3, avec sa propriété hidden (« caché »).

Avant d’exécuter : le paragraphe sera-t-il encore dans l’onglet Éléments ?

semaine-08/pas-a-pas-dom/app.js
// hidden : masque le paragraphe, sans le supprimer
note.hidden = true;

Enregistrez, puis rechargez.

Vous devez voir : la phrase « Un musée de France, en Bretagne. » a disparu de la page. Dans l’onglet Éléments, le <p hidden> est toujours à la fin de <main> : il est masqué, pas supprimé. Remplacez true par false, enregistrez, rechargez : la phrase revient. Remettez true.

Perdu ? Copiez rattrapage/dom/etape-5/app.js à la place de votre app.js.

Étape 6 — Poser une classe CSS. Ouvrez pas-a-pas-dom/style.css : à la fin, la classe .important est déjà écrite (du gras, une barre bleue à gauche). Posez-la sur le paragraphe de la ville, avec classList.add.

Avant d’exécuter : faut-il écrire le point de .important dans classList.add ?

semaine-08/pas-a-pas-dom/app.js
// classList.add : ajoute la classe CSS important à la ville
document.querySelector('#ville').classList.add('important');

Enregistrez, puis rechargez.

Vous devez voir : « Concarneau » en gras, avec une barre bleue à gauche. Dans l’onglet Éléments : <p id="ville" class="important">. Le style est écrit dans style.css ; JavaScript pose seulement la classe, sans point : le point appartient aux sélecteurs CSS.

Perdu ? Copiez rattrapage/dom/etape-6/app.js à la place de votre app.js.
