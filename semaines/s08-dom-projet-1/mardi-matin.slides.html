Logique et affichage, l’exemple minimal

import { MUSEUMS } from '../data/musees-bretagne.js';
import { museumLabel } from './logic.js';

const list = document.querySelector('#liste');
for (const museum of MUSEUMS) {
  const item = document.createElement('li');
  item.textContent = museumLabel(museum);
  list.append(item);
}

Les lignes import (2 min)

Attention

Les lignes import sont déjà écrites dans vos fichiers : ne les modifiez pas. Elles ne marchent que si la page est servie par Live Preview (une adresse en http://). Ouverte par un double-clic (file://), la page reste vide et la console parle de CORS (fiche « Lire un message d’erreur »). Les modules sont expliqués en semaine 10.

Logique et affichage — attention et vérification

Attention

ReferenceError: document is not defined en lançant les tests : votre logic.js touche à la page. Déplacez cette ligne dans app.js : la logique ne fait que calculer et renvoyer.

Logique, étape 1

export function museumLabel(museum) {
  // Le nom, un tiret, la ville : un texte, sans document
  return `${museum.Nom_officiel} - ${museum.Ville}`;
}

Logique, étape 3

export function inDepartment(museums, department) {
  // filter : garde les musées de ce département
  return museums.filter((item) => item.Departement === department);
}

Logique, étape 4

// La logique calcule : les musées du Morbihan
const morbihan = inDepartment(MUSEUMS, 'Morbihan');
// Le résumé de la page
const summary = document.querySelector('#resume');
// L'affichage écrit le résultat dans le résumé
summary.textContent = `${morbihan.length} musées dans le Morbihan`;
