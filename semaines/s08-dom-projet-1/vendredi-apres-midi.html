Groupe B : projet & consolidation

Groupe B en formation de 12 h 45 à 17 h ; le groupe A est au sport (13 h 15 – 16 h).
Pas de notion nouvelle : on termine, on avance dans le projet, puis le défi de la semaine.

Au programme

  1. Terminer : les paliers 1 de la semaine.
  2. Le projet : US-3, le détail d’un musée.
  3. Le défi de la semaine : la frise du sémaphore.
  4. À rendre mardi 01/12 : le lien de votre commit.

Aucune notion nouvelle : le DOM, la logique et l’affichage, les événements, la décomposition, la validation et la faille XSS ont été vus cette semaine. Rien de ce qui se fait cet après-midi n’est nécessaire pour lundi : le groupe A fera US-3 mercredi 02/12, avec le parcours de la semaine 9.

Dans cet ordre. Le projet passe avant le défi ; un palier 1 de la semaine non fini passe avant le défi.

1. Terminer, seul (30 min) : les paliers 1 de la semaine que vous n’avez pas validés, dans l’ordre des jours. La liste des exercices est dans la fiche de révision. Tout est validé ? Passez directement au projet.

2. Le projet : US-3, le détail (1 h 30). Sur une branche us-3-detail :

  1. La logique : findMuseum(museums, id) renvoie le musée dont l’Identifiant vaut id, ou undefined. node --test --test-name-pattern=findMuseum projet-1.test.js.
  2. L’affichage : dans showList, chaque musée devient un <button type="button"> dans son <li>, avec son propre écouteur click, comme l’exercice e3 de mardi. Le clic affiche, dans la <section id="detail">, au moins trois informations du musée, avec createElement et textContent.
  3. Livrer : Pull Request relue avec la grille, fusion, git pull.

Réussi si : node --test projet-1.test.js affiche ℹ fail 0 (les cinq tests) ; un clic, ou Entrée, sur un musée affiche son détail ; la PR est fusionnée.

3. Le défi de la semaine, seul (1 h 15) : le palier 1 (30 min), puis le palier 2 (45 min). Le palier 3 est pour ceux qui ont fini.

4. Ensuite, si vous avez fini : relisez une Pull Request d’un camarade avec la grille de relecture, et écrivez un commentaire (une chose bien faite, ou un code smell, avec la ligne). Vous préférez relire seul ? Relisez votre propre PR de US-1 avec la grille.

Défi de la semaine : la frise du sémaphore

  • Une maquette à reproduire : une carte, puis une page.
  • Tout est fourni : textes, image, police, guide de style.
  • Dossier defi-s08-frise, dans l’archive de la semaine.
  • À rendre mardi 01/12 : le lien de votre commit.

Le principe. Dans une entreprise, l’intégrateur reçoit une maquette (l’image de la page attendue), un guide de style (les couleurs, la police, les tailles) et les textes. Il écrit le HTML et le CSS qui donnent la même page, sur un téléphone comme sur un ordinateur. Chaque semaine, un nouveau défi vous entraîne à ce métier, avec des notions déjà vues seulement. Celui-ci : HTML et CSS (semaines 5 et 6), position (R1, R2), le focus visible (semaine 5) ; au palier 3, les méthodes de tableau et les objets (semaine 7), le DOM et les événements (cette semaine).

Le dossier. Il est dans l’archive de la semaine, déjà extraite dans semaine-08 : defi-s08-frise/. Ouvrez d’abord README.md (les user stories et la liste de contrôle), puis guide-de-style.md et contenu.md. Le sémaphore, la pointe de Kerbrézen et le musée sont inventés pour le cours.

À rendre, mardi 01/12 avant 15 h 30 : le lien de votre dernier commit du défi dans dwwm-tp (sur GitHub, ouvrez le commit, copiez l’adresse de la page), envoyé au formateur. Rendez ce que vous avez fait cet après-midi : le travail à la maison n’est jamais obligatoire. Mardi 01/12, de 15 h 30 à 17 h, le groupe B corrige le défi ensemble, avec le formateur.

La liste de contrôle, pour chaque palier, avant de dire « fini » :

  1. Vous devez voir : votre page ressemble à la maquette, à 375 px et à 1280 px (outils du navigateur, mode appareil).
  2. Le validateur du W3C : collez votre HTML dans l’onglet Validate by Direct Input : aucune erreur.
  3. WAVE : aucune erreur, aucune erreur de contraste.
  4. Lighthouse, catégorie Accessibilité : 90 ou plus.
  5. Au clavier : avec Tab, chaque lien a un contour bien visible.

Palier 1 — La carte d’une date

  1. Étape 1 : le HTML de la carte, dans etape.html.
  2. Étape 2 : la page.
  3. Étape 3 : la carte et sa ligne.
  4. Étape 4 : l’année sur la carte (R1).
  5. Étapes 5 et 6 : le titre, le thème, le lien au clavier.

Palier 1 : guidé. Durée indicative : 30 min. Dossier defi-s08-frise, fichiers etape.html et style.css. La police et les couleurs sont déjà écrites en haut de style.css. Vous tapez le code et ses commentaires, une étape à la fois. En HTML, un commentaire s’écrit <!-- … --> ; en CSS, /* … */.

La maquette. Votre carte doit ressembler à celle-ci ; à droite, au focus du clavier :

Avant de commencer. Ouvrez defi-s08-frise/etape.html avec Live Preview, puis Ouvrir dans le navigateur. Vous devez voir : le titre « Une date de l’histoire », en police du système, sur un fond blanc.

Étape 1 — Le HTML de la carte. Dans etape.html, à la place de la ligne de commentaire « Palier 1, étape 1 », tapez la carte. Les textes viennent de contenu.md.

semaine-08/defi-s08-frise/etape.html
<!-- La carte : un article, une date -->
<article class="etape">
  <!-- L'année, posée sur le haut de la carte -->
  <p class="etape-annee">1862</p>
  <!-- Le titre de la date -->
  <h2 class="etape-titre">La construction</h2>
  <!-- Ce qui s'est passé -->
  <p>Des maçons bâtissent le sémaphore en granit, au bout de la pointe de Kerbrézen.</p>
  <!-- Le thème de la date -->
  <p class="etape-theme">Le bâtiment</p>
  <!-- Le lien vers la frise (palier 2), dans un paragraphe -->
  <p><a class="etape-lien" href="#frise">Voir la salle</a></p>
</article>

Enregistrez, puis rechargez la page du navigateur.

Vous devez voir : « 1862 », le titre « La construction » en gras, la phrase, « Le bâtiment » et le lien souligné « Voir la salle », l’un sous l’autre. Rien n’est encore mis en forme : c’est le travail du CSS.

Perdu ? Copiez rattrapage/defi-s08-etape/etape-1/etape.html à la place de votre etape.html.

Étape 2 — La page. Les valeurs viennent de guide-de-style.md. Dans style.css, sous la ligne « Palier 1 : écrivez vos règles… » :

  /* L'espace intérieur */

Vous devez voir : le fond gris très clair, et tout le texte dans la police Atkinson Hyperlegible : regardez le « l » de « salle » : il a une petite queue en bas. Sinon, la police n’est pas chargée : vérifiez le nom "Atkinson" dans votre règle body.

Perdu ? Copiez rattrapage/defi-s08-etape/etape-2/style.css à la place de votre style.css.

Étape 3 — La carte et sa ligne. Sous la règle main :

semaine-08/defi-s08-frise/style.css

Vous devez voir : un bloc blanc aux coins arrondis, centré, avec un bord fin gris et, à gauche, une ligne bleu mer plus épaisse : c’est la ligne de la frise.

Perdu ? Copiez rattrapage/defi-s08-etape/etape-3/style.css.

Étape 4 — L’année sur la carte (R1). L’année sort du flux et se pose à cheval sur le haut de la carte. Son repère est la carte : position: relative est déjà écrit dans .etape, à l’étape 3.

Avant d’enregistrer : avec top: -0.9rem, l’année sera-t-elle dans la carte, ou un peu au-dessus ?

semaine-08/defi-s08-frise/style.css
/* L'année, posée sur le haut de la carte (R1) */
.etape-annee {
  /* absolute : sortie du flux, placée dans le repère */
  position: absolute;
  /* Un peu au-dessus du bord de la carte */
  top: -0.9rem;
  /* A 16 px du bord gauche */
  left: var(--espace-moyen);
  /* Pas de marge : un paragraphe en a une */
  margin: 0;
  /* L'espace intérieur de la pastille */
  padding: 0.125rem 0.75rem;
  /* Le texte blanc */
  color: #ffffff;
  /* Le texte en gras */
  font-weight: 700;
  /* Le texte un peu plus petit : 14 px */
  font-size: 0.875rem;
  /* Le fond couleur mer */
  background: var(--couleur-mer);
  /* Des bords tout ronds */
  border-radius: 999px;
}

Vous devez voir : la pastille bleu mer « 1862 », en blanc et en gras, posée sur le bord du haut de la carte, à gauche. Une valeur négative de top fait remonter l’élément au-dessus du haut de son repère. Sans position: relative sur .etape, la pastille se placerait par rapport à la page entière : tout en haut de l’écran.

Perdu ? Copiez rattrapage/defi-s08-etape/etape-4/style.css.

Palier 2 — La page de la frise

  1. Créez index.html : en-tête, trois sections, pied de page.
  2. Textes et image : contenu.md, images/.
  3. style.css : en-tête collé en haut (R2), haut de page en grille.
  4. Mobile first : 1 colonne, puis 2 à partir de 48rem.
  5. Réussi si : la page ressemble à la maquette.

Palier 2 : recommandé, semi-guidé. Durée indicative : 45 min. Vous écrivez deux fichiers sur trois : index.html, que vous créez, et la suite de style.css. Les règles du palier 1 servent telles quelles : chaque date de la frise est la carte du palier 1.

  1. Dans defi-s08-frise, créez index.html, avec la même tête que etape.html et le titre « Le sémaphore de Kerbrézen - Musées de Bretagne ».
  2. Dans body, écrivez trois parties : un header (le nom du site, puis un nav avec les deux liens du menu), un main, un footer (les deux phrases du pied de page).
  3. Dans main, trois section :
    • le haut de la page : l’image, puis un bloc avec le titre en h1, le lieu et le texte ;
    • la frise, avec l’identifiant frise : le titre « Cinq dates » en h2, puis une liste numérotée (ol) de cinq li, chacun avec une carte du palier 1. Le titre de chaque carte devient un h3 (la page a déjà un h1 et un h2), avec la même classe etape-titre ;
    • les chiffres, avec l’identifiant chiffres : le titre « En chiffres » en h2, puis une liste (ul) de trois chiffres.
  4. Vérifiez la page sans style d’abord : tout le contenu est là, dans l’ordre de la maquette.
  5. Dans style.css, à la suite du palier 1 : l’en-tête qui reste en haut quand on fait défiler (R2) ; le contenu centré, 64rem au plus ; la frise sans puces, centrée, 36rem au plus ; les trois blocs des chiffres.
  6. Mobile first : une colonne sur un téléphone ; à partir de 48rem, le haut de la page sur deux colonnes (grille) et les trois chiffres sur une ligne (Flexbox). Les tailles sont dans guide-de-style.md.

Réussi si : à 375 px et à 1280 px, votre page ressemble à la maquette ; l’en-tête reste en haut quand on fait défiler ; un clic sur un lien du menu descend à la bonne section ; la liste de contrôle est passée.

Trois indices pour la page, du plus léger au plus complet. Ouvrez-les un par un : après chaque indice, essayez de nouveau avant d’ouvrir le suivant.

AstuceIndice 1 — l’idée

Écrivez tout le HTML d’abord, sans style. Puis trois choses en CSS : l’en-tête en position: sticky avec top: 0, comme R2 ; le haut de la page en grille (display: grid), avec un écart (gap) ; les chiffres en Flexbox, en colonne sur un téléphone. Une seule règle @media (min-width: 48rem) : deux colonnes pour la grille, une ligne pour les chiffres.

AstuceIndice 2 — le squelette 
<!-- body : header, puis main, puis footer -->
<!-- header class entete : p (nom du site), puis nav > ul > 2 li > a -->
<!-- main : 3 section -->
<!--   section intro : img, puis div (h1, p lieu, p texte) -->
<!--   section id frise : h2, puis ol frise > 5 li > article etape -->
<!--   section id chiffres : h2, puis ul chiffres > 3 li (strong + texte) -->
<!-- footer : 2 p -->
/* .entete : sticky en haut ; flex : nom à gauche, menu à droite */
/* main : 64rem au plus, centré */
/* .intro : grid, avec un gap ; l'image sur toute la largeur */
/* la section frise : 36rem au plus, centrée ; .frise sans puces */
/* .chiffres : flex en colonne, sans puces ; chaque li fond sable */
/* @media à partir de 48rem : h1 plus grand, .intro sur 2 colonnes, */
/*   .chiffres en ligne */
AstuceIndice 3 — la solution, moins une ligne

La partie la plus difficile : le haut de la page et les chiffres.

/* Une colonne sur un téléphone */
.intro {
  display: grid;
  gap: var(--espace-moyen);
}

.chiffres {
  display: flex;
  flex-direction: column;
  gap: var(--espace-moyen);
  margin: 0;
  padding: 0;
  list-style: none;
}

/* A partir de 48rem */
@media (min-width: 48rem) {
  .intro {
    /* Il manque une ligne : les deux colonnes de même largeur. */
    align-items: center;
  }

  .chiffres {
    flex-direction: row;
  }
}

Enregistrer et envoyer : git add defi-s08-frise, git commit -m "Ajoute la page du defi de la semaine 8", git push.

NoteAides
  • Le cours : cette page et la maquette ; R2 pour l’en-tête ; Flexbox, Grid et mobile first en semaine 6.
  • L’IA : CS50.ai (palier IA 1) : demandez pourquoi vos colonnes ne se placent pas, pas le code.
  • MDN : grid-template-columns ; flex-direction ; requêtes média.

Palier 3 — Choisir un thème

  1. Une liste des thèmes, au-dessus de la frise.
  2. logic.js : trier, filtrer, compter ; testées.
