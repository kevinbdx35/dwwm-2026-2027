Semaine 5 — Fiche de révision

Formateur

Kevin Bardoux

Une page pour réviser la semaine. Lisez-la une fois, puis cachez-la et redites chaque point avec vos mots. Le détail de chaque notion est dans la page du jour.

Le HTML (lundi)

  • Structure : <!doctype html>, html lang="fr", puis head (charset, viewport, title) et body. Sans viewport, la page est minuscule sur téléphone.
  • Sémantique : la balise dit le rôle, pas l’apparence : header, nav, main, section, footer. Un seul h1, puis h2, h3 dans l’ordre ; un alt sur chaque image.
  • Formulaire : chaque champ a son label, relié par for = id ; type adapte le clavier ; required rend le champ obligatoire.
  • Vérifier : les tests au vert, puis le validateur du W3C sans erreur.

Le CSS (mardi)

  • Règle : un sélecteur, puis propriété: valeur;. Un point-virgule oublié fait ignorer la déclaration et la suivante.
  • Sélecteurs : p (élément), .classe, #id, nav a (les liens situés dans un nav).
  • Cascade : un id bat une classe, qui bat un élément ; à égalité, la dernière règle écrite gagne. F12 barre les déclarations perdantes.
  • Box model : contenu, padding, border, margin ; box-sizing: border-box en haut de chaque feuille de style.
  • Interface propre : hiérarchie, échelle d’espacements, typographie limitée, palette limitée, alignement à gauche.
  • Variables : déclarées dans :root, utilisées avec var(--nom) ; une faute de frappe dans le nom ne donne aucune erreur.
  • Contraste : 4,5:1 au moins pour le texte, mesuré avec l’outil du navigateur (sélecteur de couleur, F12).

Une maquette (mercredi)

  • Unités : rem pour le texte, % pour les largeurs, px pour les bordures fines ; em dépend du texte du parent.
  • D’abord le HTML sémantique, sans style ; puis le guide de style en variables ; puis le mobile ; puis le grand écran.
  • Polices : téléchargées et déclarées en local avec @font-face, jamais chargées depuis les serveurs de Google.

La mise en page (jeudi)

  • Flexbox : une dimension ; display: flex sur le parent ; justify-content sur l’axe principal, align-items sur l’axe secondaire, gap entre les éléments.
  • Grid : deux dimensions ; grid-template-columns, et 1fr qui partage la place.
  • Mobile first : une colonne d’abord, puis @media (min-width: 48rem) pour les grands écrans ; jamais de défilement horizontal à 375 px.
  • Documentation : sur une page de MDN, la syntaxe, les valeurs, un exemple à essayer, puis la compatibilité.
  • GitHub Pages : dépôt public, Deploy from a branch, main, / (root) ; l’adresse est en HTTPS.

Les audits (vendredi)

  • Lighthouse : un score par catégorie ; viser 90 en accessibilité, dans une fenêtre de navigation privée.
  • WAVE : les problèmes posés sur la page ; rouge à corriger, jaune à examiner.
  • Clavier : Tab, Maj + Tab, Entrée ; le focus toujours visible, jamais outline: none sans remplacement.
  • Accessibilité : le RGAA et la directive européenne en font une obligation ; un HTML sémantique en est la première réponse.
