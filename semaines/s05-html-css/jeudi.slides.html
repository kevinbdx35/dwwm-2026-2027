Apport 1 — Flexbox (10 min)

Flexbox — attention et vérification

Attention

display: flex se met sur le parent (le nav), pas sur les enfants (les liens). Sinon, rien ne bouge.

  • Vérifiez : quelle propriété pour centrer verticalement ?

Flexbox Froggy (40 min)

  2. Placez les grenouilles sur leurs nénuphars, niveau par niveau.
  3. Notez chaque propriété découverte.
  4. Réussi si : les 24 niveaux ; capture du dernier niveau réussi.

Apport 2 — Grid (15 min)

Grid — attention et vérification

Attention

Trois colonnes fixes sur un téléphone : les cartes deviennent minuscules. Une seule colonne au départ, plusieurs sur grand écran : c’est l’apport de cet après-midi.

  • Vérifiez : Flexbox ou Grid pour une galerie de 9 photos ?

Lire une page de documentation — justify-content (20 min)

  • Une page de référence MDN, en anglais : toujours le même plan.
  • Syntaxe, valeurs, exemple, compatibilité : où les trouver.
  • Puis l’essayer vous-même, dans VS Code.
  • Quatre questions pour finir.

À retenir — ce matin

À retenir

  • Flexbox : une dimension ; display: flex sur le parent.
  • Grid : deux dimensions ; grid-template-columns et fr.

Débrief

  • Quand choisir Flexbox, quand choisir Grid ?
  • Où trouver les valeurs d’une propriété sur une page de MDN ?

Grid Garden (45 min)

  3. Réussi si : le niveau 12 au moins (28 pour les plus rapides).

Apport — Mobile first (15 min)

Mobile first — attention et vérification

Attention

Une media query en max-width (héritée d’un tutoriel) inverse la logique : le téléphone reçoit des corrections au lieu des styles de base. Ici, toujours min-width.

  • Vérifiez : à 375 px, combien de colonnes dans l’exemple ?

« Layout Lab » (1 h 30)

  1. Mettez en page votre page personnelle, en mobile first.
  2. En-tête et menu : Flexbox ; projets ou compétences : Grid.
  3. Une media query en min-width pour les grands écrans.
  4. Vérifiez à 375 px avec le mode responsive des outils (F12).
  5. Réussi si : node --test layout.test.js passe.

Publier sur GitHub Pages (20 min)

  1. Un dépôt public à part, page-perso : dwwm-tp reste privé.
  2. git clone, puis copie de index.html et style.css ; git push.
  3. Settings → Pages → Deploy from a branch : main, / (root).
  4. Après deux minutes : pseudo.github.io/page-perso/.
  5. Réussi si : la page s’affiche, avec le cadenas (HTTPS).

À retenir — cet après-midi

À retenir

  • Mobile first : une colonne, puis @media (min-width).
  • Mise en page : vérifiez à 375 px, sans barre de défilement horizontale.
  • GitHub Pages : un dépôt public à part, Deploy from a branch, main.
