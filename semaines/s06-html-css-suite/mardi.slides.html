Après-midi — Le responsive : mobile first

Apport — Mobile first (15 min)

Mobile first — attention et vérification

Attention

Une media query en max-width (héritée d’un tutoriel) inverse la logique : le téléphone reçoit des corrections au lieu des styles de base. Ici, toujours min-width.

  • Vérifiez : à 375 px, combien de colonnes dans l’exemple ?

Pas à pas ensemble — La page en deux largeurs (55 min)

  • Je code, vous tapez en même temps : une étape à la fois.
  • Perdu ? Dossier rattrapage/responsive/.
  • Dossier : pas-a-pas-responsive.
  • F12, mode responsive, ouvert du début à la fin.

Mobile first, étape 1

/* Mobile first : la grille, pour le téléphone */
.projets {
  /* Grid : les enfants se placent en grille */
  display: grid;
  /* Mobile first : une seule colonne */
  grid-template-columns: 1fr;
  /* Grid : un espace entre les cartes */
  gap: var(--espace-3);
}

Mobile first, étape 2

/* Media query : à partir de 48rem (768 px) */
@media (min-width: 48rem) {
  /* Grand écran : la grille change */
  .projets {
    /* Grid : trois colonnes égales */
    grid-template-columns: repeat(3, 1fr);
  }
}

Mobile first, étape 3 (1/2)

/* Mobile first : l'en-tête, pour le téléphone */
.entete {
  /* Flexbox : l'en-tête est un parent flex */
  display: flex;
  /* Flexbox : logo au-dessus du menu */
  flex-direction: column;
  /* Flexbox : un petit espace entre les deux */
  gap: var(--espace-2);
}

Mobile first, étape 3 (2/2)

/* Flexbox : le menu est un parent flex */
.menu {
  /* Flexbox : les liens se placent en ligne */
  display: flex;
  /* Flexbox : un espace entre les liens */
  gap: var(--espace-3);
}

Mobile first, étape 4 (1/2)

/* Media query : à partir de 48rem (768 px) */
@media (min-width: 48rem) {
  /* Grand écran : l'en-tête change */
  .entete {
    /* Flexbox : logo et menu côte à côte */
    flex-direction: row;
    /* Axe principal : un enfant à chaque bout */
    justify-content: space-between;

Mobile first, étape 4 (2/2)

    /* Axe secondaire : centrés en hauteur */
    align-items: center;
  }

  /* Grand écran : la grille change */
  .projets {
    /* Grid : trois colonnes égales */
    grid-template-columns: repeat(3, 1fr);
  }
}
