Objectifs

  • Construire une grille à deux dimensions, et choisir entre Grid et Flexbox.
  • Écrire des styles de base pour le téléphone, puis une media query en min-width.
  • Vérifier une page à 375 et à 1280 px.

Comment se passe la journée. Une notion le matin (Grid), une notion l’après-midi (le mobile first). Chacune : une démonstration lente, un pas à pas ensemble, puis des exercices.

Matin — Grid : démonstration et pas à pas ensemble

Rappel (5 min)

  1. Sur quel élément écrit-on display: flex ?
  2. Quelle unité pour une taille de texte accessible ?
  3. Que fait un .gitignore ?

Trois questions courtes, sans regarder vos notes : la veille, la semaine passée, puis plus loin. Répondez sur une feuille ; la correction suit, à l’oral.

Apport — Grid (20 min)

  • Pourquoi : ranger des cartes en lignes et en colonnes.
  • Grid : un parent display: grid place ses enfants dans une grille.

Pourquoi. Une galerie de projets, une page avec en-tête, contenu et pied : il faut aligner dans les deux sens à la fois.

Définition. Grid organise en deux dimensions, lignes et colonnes (MDN Web Docs, s. d.-a, s. d.-b). grid-template-columns définit les colonnes ; 1fr est une fraction de l’espace disponible. Flexbox ou Grid ? Flexbox pour une rangée d’éléments (un menu, une liste de badges) ; Grid pour une grille à deux dimensions (des cartes, la page entière). Les deux se combinent : une grille de cartes, un menu en Flexbox.

Démonstration en direct, à ouvrir dans le navigateur : grid-template-columns sur six cartes. Elle se règle au clavier (Tab, puis les flèches) ou à la souris.

Exemple.

.projets {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

Pas à pas.

  1. display: grid sur le conteneur des projets.
  2. grid-template-columns: repeat(3, 1fr) : trois colonnes égales.
  3. gap: 1rem : l’espace entre les cartes, dans les deux sens.
  4. F12 : cliquez sur le badge grid à côté de l’élément : la grille se dessine sur la page.

Grid — attention et vérification

AvertissementAttention

Trois colonnes fixes sur un téléphone : les cartes deviennent minuscules. Une seule colonne au départ, plusieurs sur grand écran : c’est l’apport de cet après-midi.

Pas à pas ensemble — La grille de projets (1 h)

  • Je code, vous tapez en même temps : une étape à la fois.
  • À chaque étape : une question, puis « Vous devez voir ».
  • Perdu ? Dossier rattrapage/grid/, une étape à la fois.
  • Dossier : pas-a-pas-grid.

Niveau : guidé. Ouvrez pas-a-pas-grid/index.html avec Live Preview, et style.css à côté. Tout se passe dans style.css, à la fin du fichier.

Étape 1. Passez .projets en Grid.

Avant d’enregistrer : l’écran va-t-il changer ?

/* Grid : la section .projets est le parent */
.projets {
  /* Grid : les enfants se placent en grille */
  display: grid;
}

Vous devez voir : rien ne change : par défaut, une seule colonne. Dans F12, le badge grid est apparu.

Perdu ? Copiez rattrapage/grid/etape-1/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 2. Définissez trois colonnes égales.

Avant d’enregistrer : combien de cartes par ligne ?

/* Grid : la section .projets est le parent */
.projets {
  /* Grid : les enfants se placent en grille */
  display: grid;
  /* Grid : trois colonnes égales, 1fr chacune */
  grid-template-columns: repeat(3, 1fr);
}

Vous devez voir : trois cartes par ligne, sur deux lignes, collées les unes aux autres.

Perdu ? Copiez rattrapage/grid/etape-2/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 3. Ajoutez un espace.

Avant d’enregistrer : dans quels sens l’espace va-t-il s’appliquer ?

/* Grid : la section .projets est le parent */
.projets {
  /* Grid : les enfants se placent en grille */
  display: grid;
  /* Grid : trois colonnes égales, 1fr chacune */
  grid-template-columns: repeat(3, 1fr);
  /* Grid : un espace entre les cartes */
  gap: var(--espace-3);
}

Vous devez voir : le même espace entre les colonnes et entre les lignes. À 375 px, les trois colonnes sont trop étroites et la page déborde : c’est ce que corrige le mobile first, cet après-midi.

Perdu ? Copiez rattrapage/grid/etape-3/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 4. Dans F12, cliquez sur le badge grid. Essayez 1fr 2fr à la place de repeat(3, 1fr), regardez, puis remettez repeat(3, 1fr).

Avant d’enregistrer : que dessine le badge ?

Vous devez voir : la grille dessinée sur la page ; avec 1fr 2fr, une colonne deux fois plus large que l’autre.

Perdu ? Copiez rattrapage/grid/etape-4/style.css à la place de votre style.css, puis repartez avec le groupe.

Après-midi — Le responsive : mobile first

Apport — Mobile first (15 min)

  • Pourquoi : la majorité des visiteurs arrivent sur un téléphone.
  • Mobile first : les styles de base pour le téléphone, puis on enrichit.

Pourquoi. Commencer par le petit écran oblige à décider ce qui compte ; le grand écran ajoute de la place, pas de nouvelles idées.

Définition. En mobile first, les styles de base visent le téléphone (une seule colonne) ; une media query en min-width ajoute les styles des grands écrans (MDN Web Docs, s. d.-c). La balise meta name="viewport" de lundi est indispensable pour que le téléphone utilise sa vraie largeur (MDN Web Docs, s. d.-d).

Exemple.

.projets { display: grid; grid-template-columns: 1fr; }

@media (min-width: 48rem) {
  .projets { grid-template-columns: repeat(3, 1fr); }
}

Résultat : une page qui utilise ce code (un menu en Flexbox, trois projets en Grid, la media query min-width: 48rem), à trois largeurs.

Pas à pas.

  1. Écrivez la règle de base : une colonne.
  2. F12, mode responsive : réglez la largeur à 375 px ; une colonne.
  3. Ajoutez la media query ; élargissez à plus de 768 px (48 rem) : trois colonnes.

Mobile first — attention et vérification

AvertissementAttention

Une media query en max-width (héritée d’un tutoriel) inverse la logique : le téléphone reçoit des corrections au lieu des styles de base. Ici, toujours min-width.

  • Vérifiez : à 375 px, combien de colonnes dans l’exemple ?

Pas à pas ensemble — La page en deux largeurs (55 min)

  • Je code, vous tapez en même temps : une étape à la fois.
  • Perdu ? Dossier rattrapage/responsive/.
  • Dossier : pas-a-pas-responsive.
  • F12, mode responsive, ouvert du début à la fin.

Niveau : guidé. Ouvrez pas-a-pas-responsive/index.html avec Live Preview, puis le mode responsive des outils (F12).

Étape 1. Écrivez les styles de base : une colonne. Réglez F12 à 375 px, en mode responsive.

Avant d’enregistrer : à 375 px, combien de colonnes ?

/* Mobile first : la grille, pour le téléphone */
.projets {
  /* Grid : les enfants se placent en grille */
  display: grid;
  /* Mobile first : une seule colonne */
  grid-template-columns: 1fr;
  /* Grid : un espace entre les cartes */
  gap: var(--espace-3);
}

Vous devez voir : une colonne à 375 px ; et encore une seule à 1280 px : c’est le départ.

Perdu ? Copiez rattrapage/responsive/etape-1/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 2. Ajoutez la media query, à la fin du fichier. Élargissez, puis réduisez.

Avant d’enregistrer : à 1280 px, combien de colonnes ? Et à 375 px ?

/* Media query : à partir de 48rem (768 px) */
@media (min-width: 48rem) {
  /* Grand écran : la grille change */
  .projets {
    /* Grid : trois colonnes égales */
    grid-template-columns: repeat(3, 1fr);
  }
}

Vous devez voir : trois colonnes à 1280 px, une seule à 375 px. Le changement se fait à 768 px.

Perdu ? Copiez rattrapage/responsive/etape-2/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 3. Écrivez les styles de base de l’en-tête, au-dessus de la media query : le logo au-dessus du menu.

/* Mobile first : l'en-tête, pour le téléphone */
.entete {
  /* Flexbox : l'en-tête est un parent flex */
  display: flex;
  /* Flexbox : logo au-dessus du menu */
  flex-direction: column;
  /* Flexbox : un petit espace entre les deux */
  gap: var(--espace-2);
}

/* Flexbox : le menu est un parent flex */
.menu {
  /* Flexbox : les liens se placent en ligne */
  display: flex;
  /* Flexbox : un espace entre les liens */
  gap: var(--espace-3);
}

Vous devez voir : à 375 px, le logo au-dessus du menu.

Perdu ? Copiez rattrapage/responsive/etape-3/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 4. Dans la media query existante, ajoutez la règle des grands écrans.

Avant d’enregistrer : où va le logo à 1280 px ?

/* Media query : à partir de 48rem (768 px) */
@media (min-width: 48rem) {
  /* Grand écran : l'en-tête change */
  .entete {
    /* Flexbox : logo et menu côte à côte */
    flex-direction: row;
    /* Axe principal : un enfant à chaque bout */
    justify-content: space-between;
    /* Axe secondaire : centrés en hauteur */
    align-items: center;
  }

  /* Grand écran : la grille change */
  .projets {
    /* Grid : trois colonnes égales */
    grid-template-columns: repeat(3, 1fr);
  }
}

Vous devez voir : à 1280 px, le logo à gauche et le menu à droite ; à 375 px, rien n’a changé.

Perdu ? Copiez rattrapage/responsive/etape-4/style.css à la place de votre style.css, puis repartez avec le groupe.
