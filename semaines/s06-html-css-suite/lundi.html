Apport — Flexbox (20 min)

  • Pourquoi : aligner des éléments sur une ligne, sans calcul.
  • Flexbox : un parent display: flex répartit ses enfants sur un axe.

Pourquoi. Un menu dont les liens s’alignent et se répartissent, une carte dont l’image et le texte se placent côte à côte : avant Flexbox, il fallait des calculs fragiles.

Définition. Flexbox dispose les enfants d’un élément sur une dimension, en ligne ou en colonne (MDN Web Docs, s. d.-a). justify-content règle l’axe principal, align-items l’axe secondaire, gap l’espace entre les éléments ; flex-wrap: wrap les fait passer à la ligne si la place manque.

Démonstration en direct, à ouvrir dans le navigateur : justify-content et align-items sur un menu de trois liens. Elle se règle au clavier (Tab, puis les flèches) ou à la souris.

Exemple.

.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Pas à pas. Le formateur applique chaque ligne au menu de sa page, l’aperçu ouvert.

  1. display: flex sur le nav : les liens se mettent en ligne.
  2. justify-content: space-between : ils se répartissent sur toute la largeur.
  3. align-items: center : ils se centrent en hauteur.
  4. gap: 1rem : un espace régulier entre eux.

Les valeurs, en images

Chaque vignette est le rendu réel de son code : trois enfants A, B, C dans un parent en pointillés, qui a display: flex.

justify-content : la répartition sur l’axe principal.

align-items : l’alignement sur l’axe secondaire (trois enfants de hauteurs différentes).

flex-direction : le sens de l’axe principal.

flex-wrap : six éléments de 90 px, dans un parent trop étroit.

gap : l’espace entre les éléments.

Flexbox — attention et vérification

AvertissementAttention

display: flex se met sur le parent (le nav), pas sur les enfants (les liens). Sinon, rien ne bouge.

  • Vérifiez : quelle propriété pour centrer verticalement ?

Pas à pas ensemble — Le menu (55 min)

  • Je code, vous tapez en même temps : une étape à la fois.
  • À chaque étape : une question, puis « Vous devez voir ».
  • Perdu ? Dossier rattrapage/flexbox/, une étape à la fois.
  • Dossier : pas-a-pas-flexbox.
  • Tapez aussi les commentaires : /* … */ en CSS.

Niveau : guidé. Ouvrez pas-a-pas-flexbox/index.html avec Live Preview, et style.css à côté. Le HTML ne bouge pas : tout se passe dans style.css, à la fin du fichier.

Les commentaires. Dans chaque pas à pas, vous tapez le code et ses commentaires : ils expliquent chaque ligne et la notion en jeu. Un commentaire est sur sa propre ligne, juste au-dessus de la ligne qu’il explique. En CSS, il s’écrit /* … */ ; en HTML, <!-- … --> ; dans le terminal, il commence par #. Le navigateur les ignore : ils servent à vous relire.

Étape 1. Dans style.css, ajoutez display: flex sur le parent : la liste .menu, et non ses li.

Avant d’enregistrer : où vont aller les trois éléments de la liste ?

/* Flexbox : la liste .menu est le parent */
.menu {
  /* Flexbox : les enfants se placent en ligne */
  display: flex;
}

Vous devez voir : les trois éléments du menu, qui étaient les uns sous les autres, passent côte à côte. Ils se touchent : c’est normal, l’étape suivante le règle.

Perdu ? Copiez rattrapage/flexbox/etape-1/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 2. Ajoutez un espace entre les liens.

Avant d’enregistrer : qu’est-ce qui change, et où ?

/* Flexbox : la liste .menu est le parent */
.menu {
  /* Flexbox : les enfants se placent en ligne */
  display: flex;
  /* Flexbox : un espace entre les liens */
  gap: var(--espace-3);
}

Vous devez voir : un espace régulier entre les liens.

Perdu ? Copiez rattrapage/flexbox/etape-2/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 3. Passez l’en-tête en Flexbox, puis répartissez ses enfants.

Avant d’enregistrer : le logo et le menu sont les deux enfants de .entete : où vont-ils aller ?

/* Flexbox : l'en-tête est le parent */
.entete {
  /* Flexbox : logo et menu se placent en ligne */
  display: flex;
  /* Axe principal : un enfant à chaque bout */
  justify-content: space-between;
}

Vous devez voir : le logo à gauche, le menu à droite.

Perdu ? Copiez rattrapage/flexbox/etape-3/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 4. Centrez le logo et le menu en hauteur.

Avant d’enregistrer : align-items agit sur quel axe ?

/* Flexbox : l'en-tête est le parent */
.entete {
  /* Flexbox : logo et menu se placent en ligne */
  display: flex;
  /* Axe principal : un enfant à chaque bout */
  justify-content: space-between;
  /* Axe secondaire : centrés en hauteur */
  align-items: center;
}

Vous devez voir : les deux sont alignés sur la même ligne médiane.

Perdu ? Copiez rattrapage/flexbox/etape-4/style.css à la place de votre style.css, puis repartez avec le groupe.

Étape 5. Autorisez le retour à la ligne ; essayez ensuite à 375 px (F12, mode responsive).

Avant d’enregistrer : à 375 px, que se passe-t-il quand la place manque ?

/* Flexbox : l'en-tête est le parent */
.entete {
  /* Flexbox : logo et menu se placent en ligne */
  display: flex;
  /* Flexbox : à la ligne si la place manque */
  flex-wrap: wrap;
  /* Axe principal : un enfant à chaque bout */
  justify-content: space-between;
  /* Axe secondaire : centrés en hauteur */
  align-items: center;
}

Vous devez voir : à 375 px, aucune barre de défilement horizontale ; le menu passe à la ligne s’il manque de place.

Perdu ? Copiez rattrapage/flexbox/etape-5/style.css à la place de votre style.css, puis repartez avec le groupe.

Pas à pas, en captures

  1. Ouvrez la page de justify-content sur MDN, en anglais : developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/justify-content. Vous devez voir : le titre « justify-content CSS property », puis un encadré vert Baseline — Widely available : la propriété marche dans tous les navigateurs récents.

  1. Repérez le plan de la page, à droite : In this article. Vous devez voir : les rubriques dans l’ordre : Try it, Syntax, Description, Formal definition, Formal syntax, Examples, Specifications, Browser compatibility, See also. Un clic sur une rubrique y mène directement.

  1. Rubrique Try it : cliquez sur la ligne justify-content: space-between;. Vous devez voir : à droite, les éléments se répartissent sur la largeur. Cet exemple interactif utilise une grille : justify-content marche aussi avec Grid.

  1. Rubrique Syntax : la liste des façons d’écrire la propriété. Vous devez voir : un bloc de code, une ligne par valeur (justify-content: center;, justify-content: space-between;…), rangées par familles, avec un commentaire au-dessus de chaque famille.

  1. Sous-rubrique Values : cherchez space-between. Vous devez voir : le nom de la valeur, puis sa définition en anglais : les éléments sont répartis régulièrement ; le premier touche le bord de départ, le dernier le bord d’arrivée.

  1. Rubrique Examples, sous-titre Visualizing flex item distribution : un exemple complet, avec son code. Vous devez voir : une phrase qui présente l’exemple, puis le code CSS, avec deux boutons : Copy (copier le code) et Play (l’ouvrir dans l’éditeur en ligne de MDN).

  1. Juste en dessous, Result : le résultat de cet exemple. Vous devez voir : des cases colorées, réparties ligne par ligne, et une liste déroulante pour changer la valeur de justify-content.

  1. Rubrique Browser compatibility, en bas de la page. Vous devez voir : un tableau : une colonne par navigateur, une ligne par usage. Une coche et un numéro : la version à partir de laquelle ce navigateur reconnaît la propriété. La ligne Supported in flex layout concerne Flexbox.
