Jeudi 19/11, matin — Résumer un tableau : reduce et l’accumulateur

Compétences visées : C4 · résolution de problème

Objectifs

  • Résumer tout un tableau en une seule valeur avec reduce.
  • Expliquer le rôle de l’accumulateur et de la valeur de départ.
  • Suivre un reduce tour par tour, sur papier puis dans la console.

Comment se passe la matinée. Une seule notion : reduce. C’est la méthode la plus difficile de la semaine : nous la suivons tour par tour, au tableau, puis dans la console, avant de l’écrire.

Matin — reduce et l’accumulateur

Rappel (5 min)

  1. Que donne museum.Name si la clé s’appelle name ?
  2. display: flex : sur le parent, ou sur les enfants ?
  3. Que fait git pull ?

Trois questions courtes, sans regarder vos notes : la veille (mardi), la semaine passée, puis plus loin. Répondez sur une feuille ; la correction suit, à l’oral.

reduce (15 min)

  • Pourquoi : une seule valeur à partir de tout un tableau.
  • reduce : un accumulateur, mis à jour à chaque élément.
  • Valeur de départ : toujours donnée, en dernier argument.

Pourquoi. Le total des visites de tous les musées, le prix d’un panier, le mot le plus long : on veut une valeur, calculée à partir de tout un tableau. map et filter renvoient des tableaux ; reduce renvoie ce que vous voulez : un nombre, un texte…

Définition. reduce exécute une fonction sur chaque élément du tableau en lui transmettant le résultat du tour précédent, l’accumulateur, pour aboutir à une seule valeur (MDN Web Docs, s. d.). Le dernier argument de reduce est la valeur de départ de l’accumulateur.

reduce, en image

numbers.reduce((sum, n) => sum + n, 0), avec numbers qui vaut [3, 8, 5] :

Tour sum n Renvoyé
départ 0 — —
1 0 3 3
2 3 8 11
3 11 5 16
résultat 16

sum est l’accumulateur, n l’élément du tour, « Renvoyé » ce que la fonction renvoie. Au départ, sum vaut la valeur de départ, 0. À chaque tour, il reçoit ce que la fonction a renvoyé au tour d’avant. Le résultat est une seule valeur, 16. Le même calcul dans le visualiseur pas à pas : sum et n changent à chaque tour.

reduce, l’exemple minimal

Le premier programme de la notion, annoté :

const numbers = [3, 8, 5];

1const total = numbers.reduce(
2  (sum, n) => sum + n,
3  0,
);

4console.log(total); // 16
1
reduce reçoit deux arguments : une fonction, puis une valeur de départ.
2
La fonction reçoit l’accumulateur, sum, et l’élément du tour, n ; ce qu’elle renvoie devient le nouvel accumulateur.
3
La valeur de départ de l’accumulateur : 0 pour une somme.
4
Une seule valeur : l’accumulateur après le dernier tour.

reduce — attention et vérification

AvertissementAttention

Sans valeur de départ, reduce sur un tableau vide provoque une erreur : TypeError: Reduce of empty array with no initial value. Donnez toujours la valeur de départ : 0 pour une somme, '' pour un texte.

  • Vérifiez : [2, 4].reduce((sum, n) => sum + n, 10) ?
  • Tracez les tours sur papier, puis vérifiez dans le REPL.

Pas à pas ensemble — Le total des visites (40 min)

  • Le formateur code, vous tapez en même temps, une étape à la fois.
  • Code et commentaires : // au-dessus de chaque ligne.
  • Dossier : pas-a-pas-reduce, fichier total.js.
  • Perdu ? Dossier rattrapage/reduce/, une étape à la fois.

Palier 1 : guidé. Ouvrez pas-a-pas-reduce/total.js : les visites de trois musées des Ardennes en 2019 (Ministère de la Culture, s. d.). Dans le terminal : cd pas-a-pas-reduce. Avant l’étape 1, tracez sur votre feuille, comme au tableau, les trois tours de la somme.

Avant de commencer. Lancez node total.js, depuis pas-a-pas-reduce. Vous devez voir : les données de départ, sans erreur. Chaque étape ajoute ses lignes à la fin du fichier, et sa sortie à la fin de la console.

Étape 1 — Additionner. À la fin du fichier, additionnez les visites avec reduce, en partant de 0.

Avant d’exécuter : que va valoir le total ?

semaine-07/pas-a-pas-reduce/total.js
// reduce : additionne tout, en partant de 0
const total = visits.reduce((sum, n) => sum + n, 0);
// Une seule valeur : le total
console.log(total);

Étape 2 — Voir chaque tour. Refaites le même reduce, avec des accolades et un console.log à chaque tour.

Avant d’exécuter : au deuxième tour, que vaudra sum ?

semaine-07/pas-a-pas-reduce/total.js
// Trace : affiche chaque tour de reduce
visits.reduce((sum, n) => {
  // sum : l'accumulateur, le résultat du tour d'avant
  console.log(sum, n);
  // Avec des accolades, il faut return
  return sum + n;
}, 0);

Étape 3 — Sur des objets. Créez le tableau museums, puis additionnez le champ total de chaque objet.

Avant d’exécuter : le total sera-t-il le même qu’à l’étape 1 ?

semaine-07/pas-a-pas-reduce/total.js
// Tableau d'objets : les mêmes musées, avec leur nom
const museums = [
  // Chaque élément : un objet { name, total }
  { name: 'musée du feutre', total: 3808 },
  { name: 'musée Arthur Rimbaud', total: 29212 },
  { name: "musée de l'Ardenne", total: 51775 },
];
// reduce : additionne le champ total de chaque objet
const all = museums.reduce((sum, item) => sum + item.total, 0);
// Le même total qu'à l'étape 1
console.log(all);

Enregistrez, puis lancez node total.js dans le terminal, depuis pas-a-pas-reduce.

Vous devez voir, à la fin de la sortie :

84795

Perdu ? Copiez rattrapage/reduce/etape-3/total.js à la place de votre total.js, puis repartez avec le groupe.

Étape 4 — Le plus grand. Gardez, à chaque tour, le plus grand total vu jusque-là, avec Math.max.

Avant d’exécuter : quel nombre va sortir ?

semaine-07/pas-a-pas-reduce/total.js
// reduce : garde le plus grand total vu jusqu'ici
const best = museums.reduce(
  // max : l'accumulateur ; item : le musée du tour
  (max, item) => Math.max(max, item.total),
  // Valeur de départ de l'accumulateur
  0,
);
// Le plus grand nombre de visites
console.log(best);

Enregistrez, puis lancez node total.js dans le terminal, depuis pas-a-pas-reduce.

51775
