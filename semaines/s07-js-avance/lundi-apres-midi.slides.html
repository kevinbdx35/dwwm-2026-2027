Rappel — Les fonctions (10 min)

  • Déclarer, puis appeler avec des valeurs.
  • return : la valeur que la fonction renvoie.
semaine-07/essai.js
// Déclarer : un nom, un paramètre, un corps
function addTax(price) {
  // return : renvoie le prix TTC
  return price * 1.2;
}

// Appeler : 10 est l'argument, price vaut 10
console.log(addTax(10));

  • Et une fonction dont on a oublié le return ?

Callback et map (15 min)

  • Pourquoi : même parcours du tableau, action différente.
  • Callback : une fonction donnée à une autre, qui l’appellera.
  • map : un nouveau tableau, un résultat par élément.

Callback et map, l’exemple minimal

function addTax(price) {
  return price * 1.2;
}

const prices = [10, 25, 8];
const withTax = prices.map(addTax);
const doubled = prices.map((price) => price * 2);

console.log(withTax); // [ 12, 30, 9.6 ]

Callback et map — attention et vérification

Attention

prices.map(addTax()) appelle addTax tout de suite, au lieu de la donner à map : TypeError: number NaN is not a function. Écrivez le nom seul, sans parenthèses : prices.map(addTax).

  • Vérifiez : que donne [1, 2, 3].map((n) => n * 10) ?
  • Prédisez, puis tapez-le dans le REPL (node, puis .exit).

Map, étape 1

// Fonction : met un nom en majuscules
function shout(name) {
  // return : renvoie le nom en majuscules
  return name.toUpperCase();
}

// Appel : on donne le premier nom, on lit le résultat
console.log(shout(names[0]));

Map, étape 2

// map : appelle shout sur chaque nom (callback)
const shouted = names.map(shout);
// Affiche le nouveau tableau
console.log(shouted);

Map, étape 3

// Fonction fléchée : retire les espaces autour du nom
const trimmed = names.map((name) => name.trim());
// Affiche les noms sans espace en trop
console.log(trimmed);

Map, étape 4

// map : la longueur de chaque nom
const lengths = trimmed.map((name) => name.length);
// Affiche les six longueurs
console.log(lengths);
// Le tableau de départ n'a pas changé
console.log(names);
