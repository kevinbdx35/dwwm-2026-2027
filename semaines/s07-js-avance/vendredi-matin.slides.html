Le spread (15 min)

  • Pourquoi : changer une donnée sans abîmer l’original.
  • Spread : ... recopie les éléments dans un nouveau tableau ou objet.
  • Immutabilité : on ne modifie pas, on crée une copie modifiée.

Le spread, en image : deux étiquettes, ou deux objets

Le spread, l’exemple minimal

const names = ['musée A', 'musée B'];
const withNew = [...names, 'musée C'];
// names ne change pas ; withNew a trois éléments

const museum = { name: 'musée A', city: 'COLMAR' };
const moved = { ...museum, city: 'METZ' };

const visits = [51775, 3165];
const sorted = [...visits].sort((a, b) => a - b);
// la deuxième façon de trier sans modifier

Le spread — attention et vérification

Attention

const copie = original ne copie rien : c’est une deuxième étiquette sur le même tableau ou le même objet. Pour copier : [...original] ou { ...original }.

  • Vérifiez : const b = [...a]; b.push(1); : a a-t-il changé ?
  • Et avec const b = a; b.push(1); ?

Pas à pas ensemble — Ajouter sans modifier (25 min)

  • Le formateur code, vous tapez en même temps, une étape à la fois.
  • Code et commentaires : // au-dessus de chaque ligne.
  • Dossier : pas-a-pas-spread, fichier copies.js.
  • Perdu ? Dossier rattrapage/spread/, une étape à la fois.

Spread, étape 1

// Spread : ... recopie les éléments dans un NOUVEAU tableau
const copy = [...names];
// push ne touche que la copie
copy.push('musée Arthur Rimbaud');
// Affiche l'original, puis la copie
console.log(names, copy);

Spread, étape 2

// Spread : un nouveau tableau, avec un nom en plus à la fin
const withNew = [...names, "musée de l'Ardenne"];
// L'original n'a pas changé
console.log(names, withNew);

Spread, étape 3

// Un objet : un musée et sa ville
const museum = { name: 'musée Unterlinden', city: 'COLMAR' };
// Spread : un NOUVEL objet, avec une autre ville
const moved = { ...museum, city: 'METZ' };
// L'original garde sa ville
console.log(museum, moved);

Spread, étape 4

// Visites de trois musées
const visits = [51775, 3165, 29212];
// Spread puis sort : on trie la copie, pas l'original
const sorted = [...visits].sort((a, b) => a - b);
// Deuxième façon de trier sans modifier le tableau reçu
console.log(visits, sorted);

À retenir

À retenir

  • [...list, x] : un nouveau tableau ; { ...obj, clé: v } : un nouvel objet.
  • const b = a ne copie rien : deux étiquettes, un seul objet.
  • Trier une copie : toSorted(…), ou [...list].sort(…).
