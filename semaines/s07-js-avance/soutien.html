Semaine 7 — Soutien de la semaine

Formateur

Kevin Bardoux

Le mercredi matin, ceux qui ont un soutien prévu travaillent avec le formateur sur des exercices choisis pour eux. Ces exercices sont dans un dépôt GitHub public, à part du cours : dwwm-soutien. Cette page explique comment les récupérer ; elle ne recopie aucun exercice.

Votre numéro (E01 à E19) vous a été donné en séance. Le dossier de votre numéro contient un fichier par semaine (s07.md…) avec la liste de vos exercices.

Cloner le dépôt (une seule fois)

Dans le terminal de VS Code (Git Bash sous Windows) :

  1. Allez dans votre dossier de formation : cd ~/dwwm.

  2. Clonez le dépôt :

    git clone https://github.com/dwwm2627/dwwm-soutien.git

  3. Vérifiez : ls affiche dwwm-soutien et dwwm-tp.

Vous devez voir : un dossier ~/dwwm/dwwm-soutien, à côté de dwwm-tp.

Récupérer les exercices (chaque mercredi matin)

  1. Allez dans le dossier : cd ~/dwwm/dwwm-soutien.
  2. Récupérez les nouveaux exercices : git pull.
  3. Ouvrez le fichier de la semaine dans le dossier de votre numéro, par exemple E07/s07.md.

Vous devez voir : la liste de vos exercices de la semaine, avec un lien vers chacun.

Travailler sur un exercice

Ne modifiez rien dans dwwm-soutien : vous travaillez dans votre dépôt dwwm-tp.

  1. Créez le dossier de soutien de la semaine :

    mkdir -p ~/dwwm/dwwm-tp/semaine-07/soutien

  2. Copiez l’exercice (ici, un exercice nommé map-1) :

    cp -r ~/dwwm/dwwm-soutien/exercices/map-1 ~/dwwm/dwwm-tp/semaine-07/soutien/

  3. Ouvrez la copie dans VS Code et suivez son README.md.

  4. Enregistrez et envoyez votre travail comme d’habitude, depuis ~/dwwm/dwwm-tp : git status, git add, git commit -m "…", git push.

Vous devez voir : votre commit sur GitHub, dans votre dépôt dwwm-tp.

Si git pull refuse de se lancer

Cela arrive quand un fichier de dwwm-soutien a été modifié. Votre travail est dans dwwm-tp : vous ne perdez rien.

  1. Annulez les modifications du dossier : git restore .
  2. Relancez git pull.

Un message que vous ne comprenez pas ? Lisez-le en entier, cherchez-le dans la fiche « Lire un message d’erreur », puis demandez au formateur.
