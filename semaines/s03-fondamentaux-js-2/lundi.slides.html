Apport 1 — Les fonctions (10 min)

  • Pourquoi : écrire un calcul une fois, l’utiliser partout.
  • Fonction : un nom, des paramètres, un résultat renvoyé.
function square(n) {
  return n * n;
}

const result = square(4);
console.log(result); // 16

Fonctions — attention et vérification

Attention

console.log affiche, return renvoie. Si le test reçoit undefined, la fonction affiche au lieu de renvoyer : remplacez console.log(…) par return ….

  • Vérifiez : que renvoie square(3) ? Et square(-2) ?

Apport 2 — La portée (10 min)

  • Pourquoi : un même nom dans deux fonctions, sans conflit.
  • Portée : une variable n’existe que dans son bloc { … }.
function double(n) {
  const result = n * 2;
  return result;
}

console.log(double(3)); // 6
console.log(result);    // ReferenceError

Portée — attention et vérification

Attention

ReferenceError: … is not defined : la variable est utilisée hors de son bloc, ou son nom est mal écrit. Vérifiez où elle est déclarée.

  • Vérifiez : if (true) { const x = 1; } puis x : que se passe-t-il ?

Apport 3 — Déboguer avec méthode (20 min)

  • Pourquoi : trouver une erreur sans modifier le code au hasard.
  • Méthode : lire, isoler, tester, corriger.
/…/err.js:2
  return word[word.length - 1];
                   ^

TypeError: Cannot read properties of undefined (reading 'length')
    at lastLetter (/…/err.js:2:20)

Débogage — attention et vérification

Attention

Corrigez une chose à la fois, puis relancez tous les tests : deux changements en même temps cachent lequel a réglé le problème.

  • Vérifiez : dans l’exemple, à quelle ligne est l’erreur ?

Apport 4 — Le reste % (10 min)

  • Pourquoi : le dernier chiffre ; une division qui tombe juste.
  • a % b : le reste de la division de a par b.
console.log(1234 % 10);             // 4 : le dernier chiffre
console.log(Math.floor(1234 / 10)); // 123 : sans le dernier chiffre
console.log(12 % 3 === 0);          // true : 3 divise 12

Reste — attention et vérification

Attention

Tester « impair » avec n % 2 === 1 échoue sur les négatifs (-3 % 2 vaut -1). Testez « pair » avec n % 2 === 0.

  • Vérifiez : que vaut 57 % 10 ?
