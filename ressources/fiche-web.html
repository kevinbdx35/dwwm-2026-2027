Le Web

Fiche de lecture — fonctionnement, histoire et enjeux

Formateur

Kevin Bardoux

Lecture facultative, environ 15 minutes, en complément du fonctionnement du web (semaine 4, lundi). Support écrit par Kevin Bardoux, adapté au site du cours.

1. Qu’est-ce que le Web ?

Définition

Le Web (de l’anglais toile) est un système qui donne accès à un ensemble de ressources (pages, images, sons, vidéos) reliées par des liens hypertextes et accessibles sur le réseau Internet. Son nom complet est le World Wide Web (« toile d’araignée mondiale »), d’où le www de nombreuses adresses.

Internet ou Web ?

On confond souvent les deux, mais ce ne sont pas la même chose :

Internet Le Web
Nature Un réseau mondial de réseaux (câbles, routeurs, serveurs) Un service qui fonctionne sur Internet
Protocoles TCP/IP HTTP, HTTPS
Date Années 1970-1980 1989-1991

Le Web n’est qu’un service parmi d’autres qui utilisent Internet, comme l’e-mail (SMTP), le transfert de fichiers (FTP), la connexion à distance (SSH, semaine 4) ou la visioconférence.

2. Comment fonctionne le Web ?

Les trois piliers du Web

Tim Berners-Lee a imaginé le Web autour de trois technologies, toujours au cœur du Web actuel (CERN, s. d.) :

  • URL : une adresse unique pour chaque ressource ;
  • HTTP : le protocole qui permet de demander et d’envoyer ces ressources ;
  • HTML : le langage qui décrit le contenu des pages et les liens entre elles.

Anatomie d’une URL

https://www.exemple.fr:443/cours/web.html?page=2#historique (MDN Web Docs, s. d.-a)

Partie Exemple Rôle
Protocole https Comment communiquer
Nom de domaine www.exemple.fr Quel serveur contacter
Port 443 La porte d’entrée sur le serveur (souvent implicite)
Chemin /cours/web.html Quelle ressource demander
Paramètres ?page=2 Des informations envoyées au serveur
Ancre #historique Une position dans la page

Le modèle client-serveur

  1. Le navigateur (le client) demande au serveur DNS l’adresse IP qui correspond au nom de domaine.
  2. Il envoie une requête HTTP au serveur web, par exemple GET /cours/web.html.
  3. Le serveur renvoie une réponse HTTP : un code (200 OK, 404 Not Found…) et le contenu.
  4. Le navigateur affiche la page, puis demande les ressources liées (CSS, images, scripts).

Une requête HTTP en pratique

GET /cours/web.html HTTP/1.1
Host: www.exemple.fr
Accept: text/html

HTTP/1.1 200 OK
Content-Type: text/html

<!DOCTYPE html>
<html>…</html>

Codes à connaître : 200 (succès), 301 (redirection), 404 (introuvable), 500 (erreur du serveur) (MDN Web Docs, s. d.-b). Pour les observer : les outils du navigateur (F12), onglet Réseau.

Front-end et back-end

Front-end (côté client) Back-end (côté serveur)
Ce qui s’exécute dans le navigateur Ce qui s’exécute sur le serveur
HTML : la structure Langages : JavaScript (Node.js), PHP, Python, Java…
CSS : la présentation Bases de données : PostgreSQL, MySQL, MongoDB…
JavaScript : l’interactivité Génération des pages, authentification, API

3. Repères historiques

Aux origines d’Internet (1960-1983)

Année Événement
1960-1964 Paul Baran imagine un réseau de communication distribué, sans point central
1962 J.C.R. Licklider décrit un « réseau galactique » d’ordinateurs interconnectés
1969 Lancement d’ARPANET, financé par le ministère de la Défense américain
1971 Ray Tomlinson envoie le premier e-mail entre deux ordinateurs et choisit le @
1974 Vinton Cerf et Robert Kahn publient les principes de TCP/IP
1983 Le 1er janvier, ARPANET adopte TCP/IP : naissance de l’Internet moderne

La naissance du Web (1989-1994)

Année Événement
1989 Au CERN, Tim Berners-Lee propose un système de gestion de l’information fondé sur l’hypertexte (CERN, s. d.)
1990 Premier serveur web et premier navigateur (WorldWideWeb)
1991 Le Web s’ouvre aux utilisateurs extérieurs au CERN
1993 Le CERN place le Web dans le domaine public ; sortie du navigateur graphique Mosaic
1994 Sortie de Netscape Navigator ; création du W3C, l’organisme qui standardise le Web (W3C, s. d.-b)

Le Web 2.0 et les réseaux sociaux (2003-2010)

Année Événement
2003 Lancement de LinkedIn
2004 Lancement de Facebook ; le terme Web 2.0 est popularisé par Tim O’Reilly
2005 Lancement de YouTube
2006 Lancement de Twitter
2007 Lancement de l’iPhone : le Web devient mobile
2010 Lancement d’Instagram

Les années 2010 : l’ère des plateformes

Année Événement
2011 Lancement de Snapchat et de Google+ (fermé en 2019)
2012 Facebook dépasse le milliard d’utilisateurs
2014 HTML5 devient une recommandation officielle du W3C (W3C, s. d.-c)
2016 Lancement de Douyin, qui deviendra TikTok à l’international en 2017 ; l’expression fake news se répand
2018 Entrée en application du RGPD en Europe (CNIL, s. d.)
2020 La pandémie de COVID-19 accélère le télétravail et l’e-commerce ; l’OMS parle d’« infodémie »

Le Web3 et l’IA (2014-2026)

Année Événement
2014 Gavin Wood invente le terme Web3, pour un Web décentralisé fondé sur la blockchain (ethereum.org, s. d.)
2022 Lancement de ChatGPT : l’IA générative arrive auprès du grand public
2023 Twitter devient X ; les grands moteurs de recherche intègrent des assistants IA
2024 Le règlement sur les services numériques (DSA) s’applique aux plateformes (Commission européenne, s. d.) ; les réseaux décentralisés (Bluesky, Mastodon) gagnent en visibilité
2026 Google déploie en France ses résumés de recherche générés par IA, les « Aperçus IA » (Google France 2026)

4. Web 1.0, 2.0, 3.0

Web 1.0 Web 2.0 Web 3.0
Période vers 1991-2004 vers 2004 à aujourd’hui depuis 2014 environ, en construction
Usage Lire Lire et participer Lire, participer et posséder
Contenu Pages statiques créées par des webmestres Contenu créé par les utilisateurs Données et contenus contrôlés par les utilisateurs
Architecture Décentralisé, peu interactif Centralisé autour de grandes plateformes Décentralisé (blockchain, protocoles ouverts)
Exemples Yahoo!, MSN, sites personnels Facebook, YouTube, Wikipédia, Google Docs Ethereum, Bitcoin, Bluesky, Mastodon

D’après la présentation du Web3 d’ethereum.org (ethereum.org, s. d.).

« Web 3.0 » : deux sens à ne pas confondre

  • Le Web sémantique (Web 3.0) : la vision de Tim Berners-Lee au début des années 2000, des données structurées que les machines peuvent comprendre et relier entre elles (W3C, s. d.-d). On en retrouve des traces aujourd’hui dans les métadonnées des pages (Schema.org, le JSON-LD de la semaine 10) et les graphes de connaissances.
  • Le Web décentralisé (Web3) : le terme de 2014, un Web où les utilisateurs possèdent leurs données et leurs actifs grâce à la blockchain (cryptomonnaies, NFT, applications décentralisées) (ethereum.org, s. d.). Après l’engouement de 2021-2022, son adoption par le grand public reste limitée.

5. Enjeux actuels

  • L’IA dans la recherche : les moteurs affichent de plus en plus une réponse rédigée par IA au-dessus des liens ; en France, depuis juillet 2026, avec les Aperçus IA de Google (Google France 2026).
  • La décentralisation : des alternatives aux grandes plateformes émergent, comme Mastodon (protocole ActivityPub, une recommandation du W3C) ou Bluesky (protocole AT) (W3C, s. d.-a; Bluesky, s. d.).
  • La désinformation : les contenus trompeurs circulent vite, amplifiés par les algorithmes de recommandation et désormais par l’IA générative.
  • La régulation : l’Union européenne encadre les données personnelles (RGPD) (CNIL, s. d.), les plateformes (DSA, DMA) (Commission européenne, s. d.) et l’intelligence artificielle (AI Act).

6. Ce qu’il faut retenir

  • Le Web est un service qui fonctionne sur Internet ; ce n’est pas Internet lui-même.
  • Il repose sur trois piliers : URL, HTTP et HTML, inventés par Tim Berners-Lee au CERN en 1989-1991.
  • Le Web fonctionne selon un modèle client-serveur : le navigateur envoie des requêtes, le serveur répond.
  • Il est passé d’un Web de lecture (1.0) à un Web participatif (2.0), et tend vers un Web plus décentralisé (3.0).
  • L’IA, la régulation et la décentralisation transforment aujourd’hui la façon dont on crée et consulte le Web.
